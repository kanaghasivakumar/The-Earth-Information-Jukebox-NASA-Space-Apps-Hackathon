Generated by `python -m jukebox.pipeline --id 3912 --vmin 0 --vmax 32 --units "°C" --fps 2 --shade-invariant --l-weight 0.25 --min-chroma 5 --max-delta-e 20`
(the exact arguments are also recorded in `report.json` under `args`)

Fidelity: pitch re-extracted from `lead` matches the data curve with R² 0.986 (r 0.993, MAE 0.02 °C);
the shuffled control scores R² −1.02. 57.5% of pixels pass the colorbar match (land, flow-line gaps and
labels are masked). The lead is zoomed to the observed 18.9–19.8 °C range; band voices use the full 0–32 °C colorbar.

## Caveat: the absolute temperature depends on the inversion threshold
SST is drawn as dimmed, blended flow lines, so pixels are matched by hue (`--shade-invariant`) and
unsaturated pixels below `--min-chroma` are dropped. That cutoff shifts the recovered global mean:
min-chroma 0 → 15.1–18.2 °C, 5 → 18.9–19.8 °C (used here), 15 → 20.3–21.8 °C, 20 → 21.1–22.2 °C,
because dimmer flow lines are disproportionately cool water. The real ECCO2 global mean SST is about 18 °C,
so treat the absolute level as ±1–2 °C; the *changes over the year* are what the melody follows.
An earlier version of this demo used min-chroma 15 (unrecorded flags) and read about 2–3 °C warm.
For a ground-truth comparison see `demo/5209` (r 0.9997 against GISS GISTEMP).
